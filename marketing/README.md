## Brand

Name: **Able Recorder**. Russian name: **Эйбл рекордер**. Keep the Latin name on the app and repository.

Tagline: **Capture your screen. Keep your sound.** / **Запиши экран. Сохрани звук.**

Palette: midnight `#0C121B`, panel `#172330`, mint `#A4F4D2`, record coral `#FF785F`, white `#F3F6F5`, muted `#9CABB8`.

Typeface: **Inter**, with the [font license](fonts/OFL.txt) and [source attribution](fonts/SOURCE.md). Use Bold for headlines, Regular/SemiBold for supporting text. Keep generous clear space around the original screen/waveform/record mark; do not replace it with Ableton's logo.

Original artwork is MIT licensed with the rest of this repository. Font licensing remains separate. The Tesseract CLI is not redistributed; editable files embed the licensed font and native text/geometry layers.

## Publishing checklist

Use a release link only once the app ZIP is attached to an actual release. Clearly label the current build as an early, ad-hoc signed preview. Mention macOS 14+, Apple Silicon and Russian UI. The app records local MP4 files; it does not provide a live broadcast service.

The project is independent of Ableton and hardware manufacturers. The press kit grants no rights to their trademarks.
