# Inter

Inter by Rasmus Andersson and contributors, from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/inter
- Variable font: `Inter[opsz,wght].ttf`, stored here as `Inter.ttf`.
- License: SIL Open Font License 1.1, included as `OFL.txt`.

Acquired 2026-10-01. The font is included in the editable Tesseract compositions. The app itself uses the macOS system font.
