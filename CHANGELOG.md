# Changelog

## 0.2.0 — 2026-10-01

First Able Recorder open-source preview.

- Able Recorder / Эйбл рекордер name and original icon.
- Display capture and selectable Core Audio device/channel pair.
- Real-time H.264/HEVC + AAC MP4 with resolution, frame-rate and quality controls.
- L/R sound check, hotkey, menu bar and output folder selection.
- Direct links to macOS screen/audio permissions and current access status.
- Synthetic encode/decode tests, build/package scripts, MIT license, English/Russian guides and editable marketing kit.

This preview records local files. Live broadcasting and Developer ID notarization are not included.
